# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | ✅ Active |

## Reporting a Vulnerability

This is a defensive security tool. If you discover a vulnerability, please open an issue.

## Design Principles

- Password hashes are never logged or stored
- URL analysis is passive — no crawling or scanning
- All analysis is stateless by default
- No user data is persisted
